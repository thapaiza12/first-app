M&A CV creation — MAC APP, NO TERMINAL NEEDED

Download MA-Group-Mac-App.zip, then double-click it to extract M&A Group.app.
Drag M&A Group.app into Applications. Open it from Applications or add it to
Dock. You do not need the old .command launcher or a Terminal window.

Node.js 24+ and Python 3.12+ must be installed once. If you already installed
them for the previous version, do not reinstall them.

FIRST OPEN
This is an unsigned app. macOS may block its first launch. If so, click Done,
then System Settings > Privacy & Security > Open Anyway for M&A Group.
Do not disable Gatekeeper for your entire Mac.

First-time setup installs components in the background. A message explains
that setup can take several minutes. The browser opens when setup completes.
If Python reports certificate errors in the app log, run the official Python
installer's Install Certificates.command. Do not disable TLS checks.

GEMINI
A normal Mac dialog asks for your key once. Paste it there. Save key stores it
in your Mac login Keychain, not a text file. Choose Use local tools to skip it.
macOS may ask permission for Python to access the Keychain; allow it for this
app if you want to use the saved key. You can change it later from the app's
Gemini/local-assist settings window. Google free-tier limits and billing apply.

GEMINI + OLLAMA (optional, no API key for Ollama)
Install Ollama from https://ollama.com/download/mac and open it.
In Ollama's model selector, search for gemma3:4b and download it once.
This downloads several GB. A Mac with 16 GB RAM is recommended; speed and
availability depend on your Mac and Ollama's macOS requirements.
Keep Ollama open while using the CV app.

Open the CV app's AI settings. Choose:
- Auto: Gemini first; quota/connection failures restart the request on Ollama.
- Gemini only: no automatic switch.
- Ollama only: all AI requests stay on this Mac; Google is not used.
- OCR/templates only: no generative model.
Save AI settings, then use the connection-check button.
The same source quotations and factual checks apply to Ollama drafts.
Unverified claims never trigger a switch to a less strict workflow.
Cloud Ollama models are refused in local-only mode. Download the local model.
Long documents may exceed the local model's context limit; the app reports
this instead of silently cutting off source material. Split such documents
or select Gemini. Actual Ollama performance on your Mac is not verified here.

EVERYDAY USE
Click M&A Group in Applications/Dock. No Terminal window is opened.
Closing the browser does NOT stop the background app. Click the icon again to
reopen it. After restarting your Mac, click the icon to start it again.
To stop it deliberately, open the app's Gemini/local-assist settings and click
Stop app (アプリを停止). Your saved documents remain available next time.

YOUR DOCUMENTS
Documents are stored separately from the app in:
~/Library/Application Support/M&A Group/data
To find them in Finder, choose Go > Go to Folder and paste that location.
Back up this folder with Time Machine. Do not delete it when updating the app.

The previous Terminal version stored documents in its hidden .data folder.
This new app does not automatically copy those records. Keep the old folder.
If you have important earlier documents, ask for migration help before deleting
anything. No applicant records or API keys are included in this download.

Logs are in ~/Library/Logs/M&A Group/app.log. If setup does not finish, open
that file in TextEdit and share the error text (never an API key).

Manual editing, local text-document readers, exports and history work offline.
Gemini needs internet. Tesseract is optional for offline scans/image OCR.
No hosting account or company password is needed.

The background lifecycle and packaging are tested on Linux. macOS-specific
LaunchServices, Gatekeeper and Keychain behavior still require a real Mac test.
This app is not signed or notarized by Apple.

VERSION 0.4
This update adds larger black form text, separate résumé 入社/退社 rows, a strict
two-page résumé export check, and the six-section career document with language
skills. The browser tab is named M&A CV creation; its address remains local.
Install by stopping the old background app, then replacing the application in
Applications. Documents and the Keychain key are kept outside the app bundle.

8 GB MACS — VERSION 0.6.1
Ollama now uses a smaller 8K context and bounded response size. Text-based
PDFs can use native text directly; scanned pages are processed sequentially.
The AI waiting screen shows elapsed time and a Cancel (処理を中止) button.
No data is silently cut off to meet the limits. Large documents may need
splitting or Gemini. Factual verification is still required before drafts
are shown. Local inference speed has not been measured on your Mac.
If an earlier request is stuck, quit and reopen Ollama before trying this
version. Keep gemma3:4b installed; no model, Node or Python reinstall is needed.
